# Physio Sroka — Website und Werkzeuge (Demo)

Website für die Privatpraxis Physiotherapie Sylvia Sroka (Hannover und Hemmingen).
Gebaut aus `*.src.html` mit `python3 bau.py` (setzt Zeichen und Knopf-Pfeile ein). Gestaltung: `seite.css`, Bewegung: `seite.js`.
Schriften lokal in `schrift/`, Bilder in `media/`, gemeinsame Übungsdaten in `daten/uebungen.json`.
Werkzeuge für die Praxis liegen in `werkzeuge/`.
